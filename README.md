# Lumen Tide

A calm, pixel-art underwater game. Trace the dark water with light, touch the creatures drifting past, and let each one go. Every touch plays a note and lays a few grains of sand into a mandala, so the song and the pattern never come out the same way twice. There's no score, no timer and no way to lose.

The longer you play, the deeper you drift, from sardines near the surface down to giant isopods on the sea floor.

**Play:** open `index.html` in a browser, or visit the Netlify site.

Sound on; headphones are nice.

## Controls

- Move the mouse (or drag a finger) to leave a glowing trail
- Space: pause / play
- M: toggle music
- F: full screen

## Deploying

This is a single static `index.html` with no build step. On Netlify, import this repository and leave the build command empty with the publish directory set to the repository root (see `netlify.toml`).
